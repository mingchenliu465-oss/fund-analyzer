# 智投 · AI 基金投资分析助手（Fund Analyzer）

![Next.js](https://img.shields.io/badge/Next.js-16-black?logo=next.js)

![Python](https://img.shields.io/badge/Python-3.11%2B-3776AB?logo=python)
![Data](https://img.shields.io/badge/data-akshare-blue)

面向个人投资者的**本地**基金研究工具。装在自己电脑上运行，把基金净值、风险、回撤、持仓、市场行情和个人组合放在同一个界面里，集中回答三个问题：

1. **这只基金过去表现怎么样？**
2. **我的组合今天为什么涨跌？**
3. **我看到的数据到底新不新鲜？**

行情与净值数据来自公开接口（`akshare`，底层覆盖东方财富、天天基金、新浪公开数据）；你的个人持仓记录只保存在本地电脑，不上传任何第三方服务。

---

## 能干什么

* **首页与行情**：查看市场指数、当前交易日状态（是否开市）、热门基金与最近浏览记录。
* **看懂一只基金**：按名称或代码搜索基金，查看净值、阶段收益、年化波动率、夏普比率和最大回撤；区分场外基金、场内 ETF、LOF 三种行情语义；提供净值走势图、ETF K 线、行业分布、前十大持仓，以及同类比较与收益排名。
* **管好自己的组合**：录入买入日期、金额、净值、份额和手续费，支持单笔持仓与自动定投；查看持仓市值、成本、浮动盈亏和历史资产走势；通过今日收益归因，按单只基金拆分今天谁在贡献上涨、谁在拖累。
* **组合洞察与投资复盘**：在组合洞察里查看收益解释、持仓集中度、指数对比与历史变化；在投资复盘里查看由规则引擎按当前真实持仓生成的复盘内容。
* **基金对比与 Workbench**：把多只基金放在一起横向比较关键指标；在 Workbench 中快速搜索、标记和持续观察基金走势。
* **市场研究**：查看市场概览，以及基金的概览、表现、资金流向与持仓结构等研究数据。

### 特色功能：历史频率

只统计历史，不预测未来。取一只基金的全部历史，假定在过去任意一天买入，统计接下来 12 个月里**赚钱的频率**、**途中跌超 10% 的频率**；另外统计**跌 5% 之后，中位要等多少个交易日才回到起点**。每个数字都标明统计口径和样本范围（如样本起点数、观察窗口），并配有逐年柱状图，方便看清不同年份的差异。

### 特色功能：回测实验室（诚实回测）

规则事先写死，不许事后调参：以 250 日新高为基准，回撤达到 **10% / 15% / 20%** 时触发买入，持有 **6 个月或 12 个月**，共 6 种组合全部公开。回测只看样本外结果（留 250 日预热期），扣除手续费，并与同期买入持有策略对比。历史不足三年直接拒绝出结论，最终结论只有三档：**成立 / 不成立 / 证据不足**。

以两只常见基金的真实检验为例：对招商中证白酒指数（161725），6 种组合里 4 个不成立、2 个证据不足；对易方达沪深 300 ETF 联接（110020），6 种全部不成立。回测检验的是“逢跌买入”这条机械规则本身行不行，结论针对规则，不针对基金。

## 数据原则与立场

### 数据实话实说

核心原则只有一句：**没有数据就明确显示没有数据。**

* 不使用 mock 假行情或虚构收益，不用 `0` 代替缺失的净值、涨跌幅或风险指标。
* 基金净值、ETF 市价、ETF 净值分开处理，不混称“实时价格”；场外基金净值通常为 `T-1`。
* 收益、波动率、最大回撤优先采用累计净值口径，避免把分红误算成亏损。
* 持仓和行业配置锁定同一个报告期，不跨季度混算。
* 每条行情保留观测日期，并明确区分 `fresh`（新鲜）、`stale`（过期）、`unavailable`（不可用）状态。
* 数据源不可用时，回退到本地上次成功拉取的基金列表，并以每只基金自带的数据日期为准。

### 只讲历史，不做预测

本项目只讲历史，不做预测，页面上没有任何预测数字。这不是没试过：项目内部曾做过 22 轮严格样本外实验，验证“用净值历史预测未来涨跌和回撤概率”，结论是只靠净值历史算不出可信概率——深跌之后是继续跌还是已经跌透，在纯价格数据上无法稳定区分。回撤风险方向虽有真实但不够精确的信号，仅作内部离线研究，不对外展示。因此，产品核心只呈现真实的历史统计：历史频率、真实回撤与诚实回测。

## 怎么用

电脑上需要先安装 **Python 3.11+** 和 **Node.js 20+**，并能正常访问 `akshare` 的公开数据接口。打开 Windows PowerShell，按以下三步启动：

```powershell
# 1. 在项目根目录建虚拟环境并激活，装后端依赖
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r backend/requirements.txt

# 2. 启动后端（http://localhost:8000，健康检查 /health，接口文档 /docs）
cd backend
..\.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload

# 3. 另开一个终端，装并启动前端（http://localhost:3000）
cd frontend
npm install
npm run dev```

两端都启动后，在浏览器打开 http://localhost:3000 即可使用（前端通过 next.config.ts 自动将 /api/* 转发到本地后端）。如需生产构建，可在 frontend 目录执行 npm run build 后运行 npm run start。

数据与本地文件：个人持仓默认保存在 backend/database/portfolio.db，可通过环境变量 FUND_ANALYZER_DB_PATH 指定其他文件；数据库、日志与测试缓存均不纳入 Git；最近浏览记录只存在浏览器本地。

## 技术构成

前端：Next.js 16、React 19、TypeScript、Tailwind CSS、React Query、Recharts、Lightweight Charts。页面位于 frontend/app 下，一页一目录（backtest、history-frequency、portfolio、insights、compare、review、workbench、market、fund）。

后端：FastAPI、Pydantic、Pandas、NumPy、SQLite。代码位于 backend 下，包含 api（路由）、services（fund_service、portfolio_service、backtest_service、history_frequency、overview_service、research_service、market_data 等业务模块）、models 与 tests（包含“禁止编造数据”等数据原则的自动化守卫测试）。

数据：akshare。

关于名称里的“AI”：目前的投资复盘由规则引擎按真实持仓生成，大语言模型尚未接入（后端预留了替换接口），页面上没有 AI 自由生成的内容。
