# 智投 · AI 基金投资分析助手（Fund Analyzer）

![Data](https://img.shields.io/badge/data-akshare-blue)

这是一个运行在自己电脑上的**本地**基金研究工具。它把基金净值、风险、回撤、持仓、市场行情和你的个人组合放在同一个界面里，集中回答三个最实在的问题：

1. **这只基金过去表现怎么样？**
2. **我的组合今天为什么涨跌？**
3. **我看到的数据到底新不新鲜？**

所有行情和净值数据都来自公开接口（`akshare`，底层覆盖东方财富、天天基金、新浪公开数据）；你的个人持仓记录只保存在自己电脑本地，不会上传给任何第三方服务。

## 能干什么

### 1. 看懂一只基金（基金分析与详情）

* **能看到什么**：按基金名称或代码搜索后，可以看到净值、阶段收益、年化波动率、夏普比率、最大回撤，以及净值走势图、ETF K 线、行业分布、前十大持仓、同类比较与收益排名。
* **帮你回答什么**：这只基金过去赚过多少钱、波动大不大、历史上最多跌过多少、里面到底重仓了哪些股票和行业、在同类里排在什么位置。
* **关键口径**：严格区分场外基金、场内 ETF 和 LOF 三种行情语义，不把不同性质的价格混为一谈；计算收益、波动率和最大回撤时优先采用**累计净值**，避免把基金分红误算成亏损；前十大持仓与行业分布锁定同一个报告期，不跨季度混算。

### 2. 历史频率：看清过去真实的赚钱与回本机会

* **能看到什么**：三类直观的历史统计数字，以及按年份展开的逐年柱状图。
* **帮你回答什么**：如果过去随便哪一天买入这只基金，拿一年赚钱的机会有多大？中途跌得让人难受的机会有多大？万一跌了，通常要熬多久才能回本？
* **统计方法与口径**：只统计历史，不预测未来。工具会取这只基金的全部历史，假定你在过去任意一天买入，统计接下来 12 个月里**赚钱的频率**和**途中跌超 10% 的频率**；另外单独统计**跌 5% 之后，中位要等多少个交易日才回到起点**。页面上每个数字都会标明统计口径和样本范围（例如样本起点数、观察窗口），配合逐年柱状图，能清楚看出不同年份的差异。

### 3. 回测实验室（诚实回测）：检验“逢跌买入”到底行不行

* **能看到什么**：6 种公开买入规则在历史数据上的样本外回测表现，以及它们和“直接买入持有”的对比结论。
* **帮你回答什么**：“跌多了再买”这种常见的机械规则，在这只基金的历史上到底有没有效？
* **关键规则与口径**：规则事先写死，不许事后调参——以 250 日新高为基准，回撤达到 **10% / 15% / 20%** 时触发买入，分别持有 **6 个月或 12 个月**，共 6 种组合全部公开。回测只看样本外结果（留出 250 日预热期），扣除手续费，并与同期买入持有策略对比；历史不足三年的基金直接拒绝出结论。最终结论只有三档：**成立 / 不成立 / 证据不足**。
* **真实检验例子**：对招商中证白酒指数（161725），6 种组合里 4 个不成立、2 个证据不足；对易方达沪深 300 ETF 联接（110020），6 种全部不成立。这个工具检验的是“逢跌买入”这条机械规则本身行不行，结论针对规则，不针对基金。

### 4. 管好自己的组合（我的组合）

* **能看到什么**：持仓市值、持仓成本、浮动盈亏、历史资产走势，以及按基金拆分的**今日收益归因**。
* **帮你回答什么**：我手里的基金一共赚了还是亏了？今天组合为什么涨跌，具体是哪几只基金在拉升、哪几只在拖累？
* **使用方式与口径**：支持录入买入日期、金额、净值、份额和手续费，同时支持单笔持仓和自动定投；今日收益归因会把当天的整体涨跌拆解到每一只持仓基金上，一眼看清贡献来源。

### 5. 组合洞察与投资复盘

* **能看到什么**：组合洞察提供收益解释、持仓集中度、指数对比和历史变化；投资复盘提供每日复盘内容。
* **帮你回答什么**：我的钱是不是太集中在少数基金上？组合表现和主要市场指数比怎么样？结合当前持仓，今天有哪些值得留意的变动？
* **关键口径**：投资复盘完全由后端**规则引擎**按你当前的真实持仓生成，不是大模型自由编造的内容。

### 6. 基金对比、Workbench 与市场研究

* **首页与行情**：打开首页即可查看市场指数、当前交易日状态（是否开市）、热门基金与最近浏览记录。
* **基金对比**：把多只基金放在一起横向比较关键指标，方便筛选和取舍。
* **Workbench**：用来快速搜索、标记和持续观察你关注的基金走势。
* **市场研究**：提供市场概览，以及单只基金的概览、阶段表现、资金流向和持仓结构等研究数据。

## 数据原则与立场

### 数据实话实说（项目铁律）

核心只有一句：**没有数据就明确显示没有数据。**

* 不使用 mock 假行情或虚构收益，也不用 `0` 代替缺失的净值、涨跌幅或风险指标。
* 基金净值、ETF 市价、ETF 净值分开处理，不混称“实时价格”；场外基金净值通常是 `T-1`（更新到上一个交易日）。
* 收益、波动率、最大回撤优先用累计净值口径，避免把分红误算成亏损。
* 持仓和行业配置锁定同一个报告期，不跨季度混算。
* 每条行情保留观测日期，并明确区分 `fresh`（新鲜）、`stale`（过期）、`unavailable`（不可用）三种状态。
* 当外部数据源暂时不可用时，自动回退到本地上次成功拉取的基金列表，并以每只基金自带的数据日期为准。

### 只讲历史，不做预测

本项目**只讲历史，不做预测**，页面上没有任何预测数字。这不是没试过：项目内部曾做过 22 轮严格样本外实验，专门验证“用净值历史预测未来涨跌和回撤概率”，结论是只靠净值历史算不出可信概率——深跌之后是继续跌还是已经跌透，在纯价格数据上无法稳定区分。回撤风险方向虽有真实但不够精确的信号，也只作内部离线研究，绝不对外展示。因此，产品只呈现真实、可核查的历史统计：历史频率、真实回测和诚实回测。

## 怎么用

电脑上需要先安装 **Python 3.11+** 和 **Node.js 20+**，并能正常访问 `akshare` 的公开数据接口。打开 Windows PowerShell，按下面三步启动：

```powershell
# 1. 在项目根目录建虚拟环境并激活，装后端依赖
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r backend/requirements.txt

# 2. 启动后端（http://localhost:8000，健康检查 /health，接口文档 /docs）
cd backend
..\.venv\Scripts\python.exe -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload

# 3. 另开一个终端，装并启动前端（http://localhost:3000）
cd frontend
npm install
npm run dev
```

两端都启动后，在浏览器里打开 http://localhost:3000 就能使用（前端通过 next.config.ts 自动将 /api/* 请求转发到本地后端）。如需生产构建，可在 frontend 目录先执行 npm run build，再执行 npm run start。

数据与本地文件：个人持仓默认保存在 backend/database/portfolio.db，也可以通过环境变量 FUND_ANALYZER_DB_PATH 指定其他文件路径；数据库、日志和测试缓存均不进入 Git；最近浏览记录只保存在当前浏览器本地。

## 技术构成

前端：基于 Next.js 16、React 19、TypeScript、Tailwind CSS、React Query、Recharts、Lightweight Charts 构建。页面位于 frontend/app 下，一页一目录（backtest、history-frequency、portfolio、insights、compare、review、workbench、market、fund）。

后端：基于 FastAPI、Pydantic、Pandas、NumPy、SQLite 构建。代码位于 backend 下，分为 api（路由）、services（包含 fund_service、portfolio_service、backtest_service、history_frequency、overview_service、research_service、market_data 等业务模块）、models 与 tests（包含完整的自动化测试，以及“禁止编造数据”等数据原则的守卫测试）。

数据源：akshare。

关于名称里的“AI”：目前的投资复盘由规则引擎按真实持仓生成，大语言模型尚未接入（后端已预留替换接口），页面上没有 AI 自由生成的内容。
